# BatteryCheck
Архітектура для BatteryCheck була вибрана MVVM. Було прийняте рішення реалізувати лише основну логіку без жодного дизайну чи додаткових елементів.
Запуск програми відбувається з папки App, яка містить файл BatteryCheckApp це точка входу в застосунок.
В папці Flows знаходиться основний екран з реалізацією тестового завдання. В цій папці є HomeView, який складається з файлів HomeView і HomeViewModel. HomeView  це лише екран без жодної логіки, проте в ньому є змінна для отримання логіки з HomeViewModel. Вся логіка реалізована саме в HomeViewModel він містить проперті, сервіси, а також логіку з відправкою даних.
В папці Model реалізована структура для передачі даних у форматі JSON. В папці Service реалізована основна логіка окремі сервіси для моніторингу батареї та для надсилання даних на сервер. Дані перед відправкою кодуються у Base64.
Передача даних відбувається кожні 2 хвилини, також реалізована підтримка фонових задач. Вся логіка моніторингу, збору, кодування та надсилання знаходиться в HomeViewModel. В HomeView доданий Toggle для ручного керування моніторингом.
